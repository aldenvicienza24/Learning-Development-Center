=======================================

https://biz.partnership.uisi.ac.id

Login CMS:
https://biz.partnership.uisi.ac.id/cms/login


1. STRUKTUR WEBSITE
===================

Lokasi proyek pada laptop/Laragon:
C:\UISI\web-uisi\web-uisi

Lokasi pada server Virtualmin:

/home/biz.partnership/
|-- laravel/                 Kode aplikasi Laravel
|   |-- app/
|   |-- config/
|   |-- database/
|   |   `-- database.sqlite Database produksi
|   |-- resources/
|   |-- routes/
|   |-- storage/
|   `-- vendor/
`-- public_html/             File yang dapat diakses browser
    |-- build/
    |-- images/
    |-- storage/             Gambar dan bukti pembayaran
    |-- vendor/
    |-- .htaccess
    `-- index.php

Aplikasi saat ini memakai SQLite. Data website berada di:
/home/biz.partnership/laravel/database/database.sqlite

Menu Edit Databases di Virtualmin menampilkan MariaDB, tetapi MariaDB tersebut
belum digunakan oleh aplikasi ini.


2. DEPLOYMENT PERTAMA DARI AWAL
===============================

Bagian ini hanya dipakai untuk pemasangan pada server kosong.

A. Persiapan di Laragon

1. Buka terminal pada folder:
   C:\UISI\web-uisi\web-uisi

2. Jalankan:

   composer install
   npm install
   php artisan migrate
   npm run build
   php artisan test

3. Jika website lokal berjalan, buat paket hosting:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deployment\build-virtualmin-package.ps1

4. Paket penuh hanya dipakai untuk deployment pertama. Jangan gunakan paket
   penuh untuk update website yang sudah menerima data pendaftaran.

B. Upload ke Virtualmin

1. Buka File Manager.
2. Masuk ke folder home /home/biz.partnership.
3. Upload ZIP hosting.
4. Extract di folder home tersebut.
5. Pastikan folder laravel sejajar dengan public_html.
6. Gunakan PHP 8.2 atau lebih baru.
7. Pastikan modul berikut aktif:
   - pdo_sqlite
   - sqlite3
   - mbstring
   - fileinfo
   - gd
   - xml
   - zip

8. Permission yang diperlukan:

   laravel/storage                 0775
   laravel/bootstrap/cache         0775
   database/database.sqlite        0664
   public_html/storage             0775
   Direktori aplikasi lainnya      0755
   File PHP lainnya                0644
   laravel/.env                    0600

9. Buka website dan halaman login CMS.
10. Setelah berhasil, hapus ZIP dari server.

4. MEMPERBARUI TAMPILAN ATAU UI DARI LARAGON
============================================

Gunakan langkah ini untuk perubahan Blade, CSS, JavaScript, navbar, halaman
admin, dan desain lainnya.

A. File UI utama

resources/views/             Semua halaman Blade
resources/views/admin/       Tampilan CMS
resources/views/partials/    Navbar, footer, dan komponen umum
resources/css/app.css        CSS utama
resources/js/admin-analytics.js  JavaScript analitik admin
public/images/               Gambar bawaan

B. Ubah dan tes secara lokal

1. Lakukan perubahan di Laragon.
2. Buka dan periksa website lokal.
3. Jalankan:

   npm.cmd run build
   php artisan test

4. Hasil build frontend terbaru berada di:

   public/build

C. Struktur ZIP update UI

Siapkan struktur berikut:

update-ui/
|-- laravel/
|   |-- app/                 Jika controller atau model berubah
|   |-- config/              Jika konfigurasi berubah
|   |-- resources/
|   `-- routes/              Jika route berubah
`-- public_html/
    |-- build/
    `-- images/              Hanya jika gambar bawaan berubah

Di dalam ZIP, level paling atas harus langsung berisi:

laravel/
public_html/

Jangan sampai hasil extract menjadi:

/home/biz.partnership/update-ui/laravel

D. File yang tidak boleh dimasukkan ke ZIP update

.env
database/database.sqlite
laravel/storage
public_html/storage
node_modules
vendor
tests
logs
scratch

Jangan upload public/index.php lokal secara langsung. Versi server memiliki
path khusus menuju /home/biz.partnership/laravel.

E. Upload update UI

1. Backup database dan storage terlebih dahulu.
2. Upload ZIP ke /home/biz.partnership.
3. Extract di folder tersebut.
4. Pilih Replace atau Overwrite jika diminta.
5. Jangan menghapus folder storage.
6. Jika tersedia Terminal, jalankan:

   cd /home/biz.partnership/laravel
   php artisan optimize:clear

7. Buka website dengan Ctrl + F5.
8. Periksa halaman utama dan CMS.
9. Setelah berhasil, hapus ZIP update dari server.

6. MEMPERBARUI STRUKTUR DATABASE
===============================

Gunakan migration untuk menambah kolom atau tabel. Jangan mengubah database
produksi secara manual jika perubahan dapat dibuat dengan migration.

A. Membuat migration lokal

Contoh:

php artisan make:migration add_location_to_programs_table

Edit file migration baru di:

database/migrations/

Tes secara lokal:

php artisan migrate
php artisan test

B. Struktur ZIP update database

laravel/
|-- app/                     Model atau controller yang berubah
|-- database/
|   `-- migrations/          Migration baru
|-- resources/               Form atau tampilan baru
`-- routes/                  Jika route berubah

public_html/
`-- build/                   Jika UI berubah

Jangan sertakan:

laravel/database/database.sqlite

C. Menjalankan migration pada server

1. Backup database terlebih dahulu.
2. Upload dan extract ZIP update.
3. Buka Terminal atau SSH.
4. Jalankan:

   cd /home/biz.partnership/laravel
   php artisan migrate --force
   php artisan optimize:clear

5. Jika perintah php bukan PHP 8.2, gunakan:

   php8.2 artisan migrate --force
   php8.2 artisan optimize:clear

Jika Virtualmin tidak menyediakan Terminal, minta administrator server atau
buat runner migration sekali pakai yang memakai kunci dan menghapus dirinya
setelah selesai.

==================================

maka file berikut berubah:

vendor/

Pada server jalankan:

cd /home/biz.partnership/laravel
composer install --no-dev --optimize-autoloader

Jika server tidak memiliki Composer atau SSH, buat paket update yang sudah
menyertakan vendor produksi.
